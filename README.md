# Student Hub

Адаптивная панель для расписания, занятий в Zoom и ссылок на Google Classroom. Приложение создано на HTML, CSS и чистом JavaScript.

## Запуск

1. Откройте папку проекта в редакторе кода.
2. Запустите локальный веб-сервер (например, расширение Live Server в VS Code) и откройте через него `index.html`.
3. Файл `schedule.docx` загружается и отображается автоматически. Для просмотра DOCX требуется подключение к CDN `docx-preview`.
4. Для переключения светлой и тёмной темы используйте кнопку в верхней панели.
5. Чтобы открыть панель администратора, введите код `m4B8vN3tQ`, точно соблюдая регистр букв. После авторизации в разделе расписания станет доступна загрузка другого файла DOCX.

## Состав проекта

- `index.html` — структура приложения, навигация и окна авторизации/администрирования
- `styles.css` — адаптивные стили и темы оформления
- `app.js` — навигация, отображение DOCX, панель администратора и сохранение ссылок в `localStorage`
- `schedule.docx` — расписание, отображаемое по умолчанию
- `assets/logo.svg`, `assets/favicon.svg` — фирменные векторные изображения

## Важно о безопасности

Это демонстрационное приложение без серверной авторизации. Код доступа находится в `app.js`, а данные в браузере можно просмотреть или изменить. Не используйте этот механизм для защиты конфиденциальной информации. Для реального доступа перенесите авторизацию на сервер, ограничьте попытки входа и храните данные в защищённой базе/API.

Ссылки сохраняются в `localStorage` текущего браузера. Начальные ссылки на Zoom и Google Classroom — примеры; замените их настоящими адресами.

## Просмотр DOCX

Для отображения используется `docx-preview` с CDN, поэтому необходим доступ к интернету. Файл расписания обрабатывается локально в браузере и не отправляется на сервер. Автоматическая загрузка `schedule.docx` работает при запуске через локальный или удалённый веб-сервер; при открытии `index.html` напрямую через `file://` браузер блокирует такую загрузку.
